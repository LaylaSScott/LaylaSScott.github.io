Labs

Lab 0

This lab was a introduction to the class and tools we will use. We set up a virtual machine and utilized git to create a private repository.

Lab 1

In this lab, we learned about HTTP Protocol and capturing and analyzing packets. We also learned about web application programming and HTTP GET vs. POST requests, and creating CGI and PHP web applications.

Lab 2

In this lab, we created an HTML file and updated it with forms, JavaScript code, and CSS to improve the aesthetics of the page. We also used Ajax and jQuery to send GET and POST requests to a previously created web application, and integrated a web API.
